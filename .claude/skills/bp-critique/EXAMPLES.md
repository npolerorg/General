# Ejemplos de invocación

## Ejemplo 1: Revisar una lámina recién editada
Usuario: "Acabo de actualizar la lámina 4 del deck Toyosa. Aplicá B|P Critique antes de presentármela."

Tu workflow:
1. Leer el HTML del deck (toyosa-directorio-v06.html o vXX)
2. Extraer lámina 4
3. Invocar orquestador
4. Devolver lámina + Pre-flight Report

## Ejemplo 2: Investigación dirigida
Usuario: "B|P Critique con énfasis en Research: necesito validar el dato de crédito automotriz Bolivia que dije que era 22%."

Tu workflow:
1. Invocar SOLO ROLE-RESEARCH.md
2. Hacer 3-5 búsquedas web específicas
3. Triangular fuentes
4. Devolver dossier

## Ejemplo 3: Pre-flight full del deck completo
Usuario: "Aplicá Pre-flight Check al deck v0.7 completo antes de mostrármelo."

Tu workflow:
1. Leer las 19-20 láminas
2. Invocar orquestador, los tres roles en paralelo
3. Sintetizar todo en un solo reporte
4. Devolver: deck + reporte consolidado
