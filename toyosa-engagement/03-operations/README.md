# 03 · Operations

Datos operativos de las BUs: inventario, ventas, logística, transacciones.
Fuente primaria: Tableau (operacional) y Alchemy (transaccional).

- `inventory/` — stock por marca, modelo, sucursal, antigüedad
- `sales/` — ventas YTD por canal, sucursal, marca, vendedor
- `logistics/` — importaciones, despachos, tiempos
- `transactions/` — detalle transaccional (sample / extractos)

Datos en bruto están en `.gitignore`.
