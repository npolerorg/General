# 07 · Deliverables

Entregables finales del engagement, listos para distribución al Directorio
de Toyosa.

- `decks-html/` — versión HTML autocontenida (canónica)
- `decks-pdf/` — exportación PDF para distribución
- `reports-docx/` — reportes complementarios en Word cuando el Directorio
  lo pide

Cada archivo nombrado `toyosa-{bu}-{periodo}.{ext}` para mantener trazabilidad.
